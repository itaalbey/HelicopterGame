# Helicopter Prototype

Playable prototype фізично коректної моделі польоту вертольота (тестове завдання Unity developer).

- **Unity:** 6000.3.10f1, URP
- **Сцена:** `Assets/_Project/Scenes/Helicopter.unity`
- **Ввід:** Unity Input System (`Assets/_Project/Input/HelicopterControls.inputactions`)
- Готові flight-controller ассети не використовуються, вся фізика — власна, поверх `Rigidbody`.

## Керування

| Клавіша | Дія |
|---|---|
| `W` / `S` | нахил носа вниз / вгору (рух вперед / назад) |
| `A` / `D` | крен вліво / вправо (рух вліво / вправо) |
| `Q` / `E` | поворот по yaw |
| `Space` / `Ctrl` | набір / зниження висоти (зліт / посадка) |
| `R` | респаун на стартовому гелімайданчику |

Також підтримується геймпад (ліві стік — циклічний крок, правий стік — висота та yaw, `Select` — респаун).

## Фізична модель

Вертоліт рухається **лише силами та моментами**, прикладеними до `Rigidbody`. Горизонтальний рух виникає так само, як у справжнього вертольота: нахил диска ротора відхиляє вектор тяги.

| Ефект | Реалізація |
|---|---|
| Підйомна сила / тяга | `MainRotor`: `T = collective · Tmax · rpm² · groundEffect`, прикладена в точці втулки вздовж осі валу |
| Ефект землі | формула Cheeseman–Bennett `1 / (1 − (R / 4z)²)` за даними радіовисотоміра |
| Реактивний момент ротора | `MainRotor`: момент на фюзеляж, пропорційний тязі, — без хвостового гвинта вертоліт закручується |
| Хвостовий гвинт | `TailRotor`: бічна сила на плечі хвостової балки (`τ = r × F`) — дає і момент рисканню, і реальний бічний «знос» |
| Циклічний крок (pitch / roll) | момент втулки, обмежений і масштабований від rpm² |
| Гравітація | стандартна `Physics.gravity` |
| Інерція | маса, центр мас і тензор інерції задаються явно (`HelicopterConfig`); моменти рахуються як `τ = I · α` |
| Drag | анізотропний квадратичний опір `F = −½ ρ CdA v|v|` по осях фюзеляжу, прикладений у центрі тиску позаду ЦМ (флюгерна стійкість) + аеродинамічне демпфування обертання |
| Двигун | плавна розкрутка / зупинка ротора, тяга й керованість залежать від rpm |

Параметри відповідають вертольоту класу UH-1Y: маса 5500 кг, моменти інерції UH-1, радіус несучого гвинта 6.55 м, плече хвостового гвинта 9 м, тягоозброєність 1.8.

### Система стабілізації (SAS)

Пілот не керує сирими силами — як і в сучасних вертольотах, між ручкою та ротором стоїть автоматика:

- **Вертикальний канал** — ввід задає вертикальну швидкість; без вводу — утримання висоти. Collective pitch = feed-forward висіння (вага / доступна тяга) + PI-регулятор. Біля землі швидкість зниження плавно обмежується → м'яка посадка.
- **Pitch / Roll** — ручка задає кут нахилу, контур другого порядку (ωn, ζ) відпрацьовує його. Без вводу — **hover hold**: апарат нахиляється проти знесення і зупиняється з інерцією.
- **Feed-forward відомих збурень** — тяга хвостового гвинта зносить вертоліт убік і (бо гвинт вище центру мас) кренить його. Як і реальний пілот UH-1, автоматика тримає невеликий лівий крен (`atan(T_хв / вага)` ≈ 5°) і компенсує момент хвостового гвинта циклічним кроком, тому вертоліт висить на місці.
- **Yaw** — педалі задають кутову швидкість; без вводу курс тримається. Хвостовий гвинт додатково компенсує реактивний момент головного ротора.
- На землі (стан `LANDED`) автоматика вимикається, collective плавно йде в нуль.

## Архітектура

```
Assets/_Project/Scripts          (asmdef: HelicopterGame)
├── Helicopter
│   ├── HelicopterConfig         усі налаштування (ScriptableObject)
│   ├── HelicopterBody           маса / ЦМ / інерція, опір повітря і демпфування
│   ├── HelicopterEngine         обороти ротора
│   ├── MainRotor                тяга, ефект землі, реактивний і циклічний моменти
│   ├── TailRotor                анти-момент і yaw
│   ├── GroundSensor             висота над землею / контакт із землею
│   └── RotorSpinner             обертання лопатей (візуал)
├── Control
│   ├── FlightController         система стабілізації: висота, нахил, курс
│   ├── PiController             PI-регулятор
│   └── HelicopterInput          читання Input System
├── UI/HelicopterHud             телеметрія на екрані
├── Camera/ChaseCamera           камера, що слідує за вертольотом
└── Gameplay/HelicopterRespawner респаун

Assets/_Project/Configs          HelicopterConfig.asset
Assets/_Project/Models           FBX моделі UH-1Y, текстури, матеріали
Art/Helicopter                   вихідні файли моделі (OBJ, .blend)
```

- Фізика (`Helicopter`) і керування (`Control`) розділені: ротори лише прикладають сили за командами, `FlightController` лише обчислює ці команди і не рухає тіло напряму.
- Усі параметри в одному ScriptableObject — тюнінг без перекомпіляції.
- Порядок оновлення в `FixedUpdate` зафіксовано через `DefaultExecutionOrder`: двигун → сенсор → стабілізація → ротори.
- Усі об'єкти та скрипти розміщені на сцені й зв'язані через серіалізовані поля, нічого не створюється в рантаймі.

## 3D-модель

UH-1Y розділений на `Body`, `MainRotor` і `TailRotor`; pivot гвинтів — у центрах втулок, початок координат — на землі під валом.
Фізичні точки прикладання сил (`MainRotor`, `TailRotor` на корені префабу) стоять на втулках, лопаті обертає `RotorSpinner`, корпус має опуклий колайдер.
